About This Project

This Blogging Platform is created as part of the DIY Internship program. The project emphasizes production-ready architecture, clean modular code, and scalable database patterns.

Project Architecture

Application Factory Pattern

Encapsulates app initialization inside create_app() in app/__init__.py, allowing multiple environments (development, testing, production) and seamless testing.

Flask Blueprints

Application views are segregated into decoupled blueprints (main and posts) for maintainability and scalability.

Flask-SQLAlchemy ORM

Declarative data models for User and Post with one-to-many relational mappings and foreign keys.

Flask-Migrate

Schema evolution tracked through Alembic migration scripts, ensuring safe database schema upgrades and rollbacks.
