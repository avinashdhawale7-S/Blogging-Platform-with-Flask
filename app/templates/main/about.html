About FlaskBlog

A production-grade blogging application developed for the DIY Internship. The project demonstrates core Flask fundamentals, clean architectural patterns, database modeling, secure authentication, rich-text CRUD, and modern Jinja2 frontend pagination.

Core Modules & Architecture

Application Factory

Centralized initialization in create_app() with dynamic configuration, database binding, and modular Blueprint registration.

Authentication & Security

User registration, salted password hashing with Werkzeug, session tracking with Flask-Login, and authorization guards.

Rich Text CRUD & Tags

Article authoring with CKEditor 5 Classic, many-to-many tag associations, and server-side Bleach HTML sanitization against XSS.

Frontend & Pagination

Responsive Jinja2 templates, smart multi-page pagination macros, individual article views with reading time, and public author profile pages.
